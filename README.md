# pjj- · 项目合集

个人学习项目合集仓库，每个项目独立成一个子目录。

## 目录结构

```
pjj-/
├── .gitignore          # 通用忽略规则，对全部子项目生效
├── README.md
└── 矿物分类项目/        # 矿物数据清洗 + 缺失值填充 + 模型训练
    ├── 代码/            # fill_data.py / 模型最后训练.py / 深度强化训练.py / 清洗数据.py
```

## 约定

- 新项目统一放在**根目录下的独立子文件夹**中，文件夹名即项目名。
- 根目录 `.gitignore` 统一管理通用忽略项（`__pycache__`、`~$*` 锁文件、`.ipynb_checkpoints/`、模型权重等），单个项目如有特殊需要可在自己的子目录内追加 `.gitignore`。
- 每个项目**独立提交**，提交信息统一使用 `feat: <项目名> —— <简述>` / `refactor: <简述>` / `fix: <简述>` 格式。

## 环境

- Python 3.12（`uv` 管理虚拟环境）
- Jupyter Notebook（内核 `uv-lab`）
- 深度学习：PyTorch + TensorFlow
- 大模型调用：DeepSeek API（OpenAI 兼容 SDK）、LangChain
